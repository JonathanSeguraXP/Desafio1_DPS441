# Desafío 1 - Tienda en Línea

Aplicación desarrollada en React y Next.js para venta de productos tecnológicos.

## Tecnologías usadas
- Next.js
- React
- Context API
- JSON estático

## Funcionalidades
- Login simulado
- Visualización de productos
- Carrito de compras
- Confirmaciones
- Generación de factura
